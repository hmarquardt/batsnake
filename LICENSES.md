## Current runtime assets

All current cave geometry, creature placeholder geometry, shaders, particle systems, UI graphics, favicon, materials, animation behavior, and procedural audio are original project-created assets in this repository. They contain no third-party texture, model, HDR, font, or recorded-audio bytes. System fonts are referenced but not redistributed. Under the repository MIT license, commercial use and modification are permitted with the stated notice.

`assets/models/bats/hero-bat-pilot.glb` and its JSON metadata are original project-created test assets generated by `tools/create-pilot-glb.py`. They are covered by the repository MIT license: commercial use and modification are permitted with the project notice. They contain no external textures, source geometry, recordings, fonts, or embedded attribution. Other empty asset category directories remain replacement slots, not licensed asset claims. Do not add a file with unknown authorship or license. Production candidates remain “license pending” in `docs/ASSET_MANIFEST.md` and are not included.

`assets/models/bats/hero-bat.glb` and `hero-bat.metadata.json` are original project-created production assets generated deterministically by `tools/create-hero-bat-glb.py` using Python’s standard library. The geometry, skeleton, materials, and six animation clips contain no external source geometry, textures, recordings, fonts, or other third-party bytes. They are covered by the repository MIT license; commercial use, modification, and redistribution are permitted with the project notice. The generated GLB is 70,824 bytes and is reproducible from the committed generator.

Milestone 4 boa geometry, scale-relief pixels, cave displacement, limestone/roughness pixels, guano/leaf alpha masks, mineral/vegetation batches, shaders, and procedural audio are authored in project source (`SnakeRig.js`, `CaveGenerator.js`, `CaveMaterials.js`, and `AudioManager.js`). They are deterministic or runtime-synthesized, contain no retrieved bytes, and are covered by the repository MIT license. No external modeling, texture, recording, or generative-media service was used.

Milestone 6 extends that original project-created set with the authored variable cave shell, named limestone formations, collision proxies, roost silhouettes, guano beds, seep/bedding/fracture textures, pooled water detail, bounded exterior terrain/vegetation/sky, atmospheric motion, and region-aware procedural ambience. All are expressed in repository source and generated at runtime from local code. No external asset, remotely hosted byte, field recording, scan, stock texture, or generative-media output was introduced.

## Attribution checklist for future assets

For each added file, record: asset name, author/owner, exact source URL, exact license/version, retrieval date, local path, required attribution wording, commercial-use permission, modification permission, redistribution constraints, and whether the local file was modified. Preserve a copy of license/notice text when required. Share-alike or non-commercial material requires explicit project approval before inclusion.
